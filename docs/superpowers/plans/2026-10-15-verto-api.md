# Verto API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the Verto backend — a .NET 10 API with copied BillFolder auth and an offline-first sync store (`push`/`pull`) — deployed on the existing Hetzner VPS.

**Architecture:** Same Clean Architecture as BillFolder (`Domain` → `Application` → `Infrastructure` → `Api`). The server holds no planner business rules: it authenticates, validates the *format* of each synced record, and stores it in one generic `sync_records` table (`jsonb` payload) keyed by `(user_id, entity_type, id)`, with a global Postgres sequence as the pull cursor. Sync SQL is explicit Npgsql; EF Core is used for auth tables and for migrations.

**Tech Stack:** .NET 10, ASP.NET Core minimal APIs, EF Core 10.0.7 + Npgsql.EntityFrameworkCore.PostgreSQL 10.0.1, PostgreSQL 16, FluentValidation 12.1.1, Konscious Argon2, xUnit 2.9.3 + FluentAssertions 8.9.0 + Testcontainers.PostgreSql 4.15.0, Docker, GitHub Actions, nginx + Let's Encrypt, Cloudflare DNS.

**Spec:** `docs/superpowers/specs/2026-10-15-verto-design.md`

**Scope:** This is plan 1 of the spec. The KMP app (`VertoApp`) gets its own plans: (2) domain + local DB + core screens offline, (3) sync engine, (4) Tunnel Vision / reset / return-after-absence, (5) widget, tile, share target, notifications.

**Reference repo:** `~/Repos/BillFolder` — several files are copied from it with a namespace rename. Read the source file before copying if anything looks off.

## Global Constraints

- Target framework `net10.0`; package versions exactly as listed in each `.csproj` below.
- `TreatWarningsAsErrors=true` (via `Directory.Build.props`) with `.editorconfig` copied from BillFolder. Fix analyzer findings in the code you wrote; never suppress a rule repo-wide to get green.
- Code, identifiers and comments in English; user-facing API error messages in Brazilian Portuguese; commit subjects in Portuguese following BillFolder style (`feat(sync): ...`).
- Comments explain WHY only.
- The server holds no planner business rules (spec: "regras de negócio no cliente").
- Synced entity types, exactly: `inbox_item`, `task`, `step`, `anchor`, `anchor_event`, `routine`, `routine_log`, `day_energy`.
- Limits: max 500 changes per push; max 64 KB (UTF-8) per payload; pull limit default 500, max 1000.
- Conflict rule: last write **to arrive at the server** wins (spec). `clientUpdatedAt` is stored for transparency, never used for ordering.
- Every synced record has client-generated UUID `id`, soft delete via `deletedAt`, server-assigned `serverVersion` (spec).
- Signup is gated by `Auth:AllowSignup` (default `false` in production) — this is a single-user app on a public host.
- `Jwt:RefreshTokenDays = 90`: the spec's "volta depois de sumir" must not land on a login screen after two weeks away.
- Local dev Postgres on port **5433** (BillFolder dev already uses 5432).
- Production API host: `verto-api.billfolder.app` (spec fallback; swap in Task 6 if a Verto domain is bought).

## Review Focus

1. **Same UUID from two users** — the second user's push must not overwrite or reveal the first user's record. Pinned by `Pull_SameIdFromAnotherUser_IsIsolated` (Task 4).
2. **Device clocks disagree** — a push carrying an *older* `clientUpdatedAt` that arrives later still wins. Pinned by `Pull_SameIdPushedTwice_ArrivalOrderWins_EvenWithOlderClientClock` (Task 4).
3. **Two devices pushing at the same time** — no change may be skipped by a pull cursor. Pinned by `Pull_AfterConcurrentPushes_ReturnsEveryChangeInVersionOrder` (Task 4).
4. **Malformed JSON body** (truncated request from a flaky mobile connection) — must be 400, never 500. Pinned by `Push_MalformedJson_Returns400` (Task 3).
5. **Oversized payload or batch** — rejected cleanly (per-record rejection or 400), never stored or crashing. Pinned by `Push_OversizedPayload_IsRejectedWithoutBlockingTheBatch` and `Push_MoreThan500Changes_Returns400` (Task 3).

```csharp
using Microsoft.AspNetCore.Hosting;
using Microsoft.AspNetCore.Mvc.Testing;
using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.Hosting;
using Testcontainers.PostgreSql;

namespace Verto.Api.Tests.Infrastructure;

public sealed class ApiWebApplicationFactory : WebApplicationFactory<Program>, IAsyncLifetime
{
    private static readonly IReadOnlyDictionary<string, string?> TestConfiguration =
        new Dictionary<string, string?>(StringComparer.Ordinal)
        {
            ["Jwt:Issuer"] = "verto-tests",
            ["Jwt:Audience"] = "verto-tests",
            ["Jwt:Key"] = "integration-tests-only-key-with-at-least-32-characters",
            ["Jwt:AccessTokenMinutes"] = "30",
            ["Jwt:RefreshTokenDays"] = "90",
            ["Auth:AllowSignup"] = "true",
            // Exercises the same startup migration path production uses.
            ["Database:MigrateOnStartup"] = "true",
        };

    private readonly IReadOnlyDictionary<string, string?> _configurationOverrides;

    private readonly PostgreSqlContainer _database = new PostgreSqlBuilder("postgres:16-alpine")
        .WithAutoRemove(true)
        .WithLabel("com.verto.test-suite", "api-integration")
        .Build();

    public ApiWebApplicationFactory()
        : this(new Dictionary<string, string?>(StringComparer.Ordinal))
    {
    }

    private ApiWebApplicationFactory(IReadOnlyDictionary<string, string?> configurationOverrides)
    {
        _configurationOverrides = configurationOverrides;
    }

    public static ApiWebApplicationFactory Create(IReadOnlyDictionary<string, string?> configurationOverrides)
    {
        return new ApiWebApplicationFactory(configurationOverrides);
    }

    protected override IHost CreateHost(IHostBuilder builder)
    {
        // Production so minimal APIs answer malformed bodies with 400 instead of throwing.
        builder.UseEnvironment("Production");
        builder.ConfigureAppConfiguration((_, configuration) =>
        {
            var settings = new Dictionary<string, string?>(TestConfiguration, StringComparer.Ordinal)
            {
                ["ConnectionStrings:Postgres"] = _database.GetConnectionString(),
            };

            foreach (var item in _configurationOverrides)
            {
                settings[item.Key] = item.Value;
            }

            configuration.AddInMemoryCollection(settings);
        });

        return base.CreateHost(builder);
    }

    public async Task InitializeAsync()
    {
        await _database.StartAsync();

        // Building the host runs Program.cs, which applies migrations.
        _ = Services;
    }

    async Task IAsyncLifetime.DisposeAsync()
    {
        try
        {
            await base.DisposeAsync();
        }
        finally
        {
            await _database.DisposeAsync();
        }
    }
}
```

`src/Verto.Infrastructure/DependencyInjection.cs`:

```csharp
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Configuration;
using Microsoft.Extensions.DependencyInjection;
using Npgsql;
using Verto.Infrastructure.Persistence;

namespace Verto.Infrastructure;

public static class DependencyInjection
{
    public static IServiceCollection AddInfrastructure(
        this IServiceCollection services,
        IConfiguration configuration)
    {
        ArgumentNullException.ThrowIfNull(services);
        ArgumentNullException.ThrowIfNull(configuration);

        // Resolved lazily from the container so test hosts can inject the
        // connection string after Program.cs has started building services.
        services.AddSingleton(serviceProvider =>
        {
            var connectionString = serviceProvider
                .GetRequiredService<IConfiguration>()
                .GetConnectionString("Postgres");

            if (string.IsNullOrWhiteSpace(connectionString))
            {
                throw new InvalidOperationException("ConnectionStrings:Postgres não configurada.");
            }

            return new NpgsqlDataSourceBuilder(connectionString).Build();
        });
        services.AddDbContext<ApplicationDbContext>((serviceProvider, options) =>
            options.UseNpgsql(serviceProvider.GetRequiredService<NpgsqlDataSource>()));

        return services;
    }
}
```

```csharp
var builder = WebApplication.CreateBuilder(args);

if (app.Configuration.GetValue<bool>("Database:MigrateOnStartup"))

    await using var scope = app.Services.CreateAsyncScope();

    await db.Database.MigrateAsync();

    return Results.Ok(new
    {
        status = canConnect ? "ok" : "degraded",
        version = "0.1.0",
        timestamp = DateTime.UtcNow,
    });
});

await app.RunAsync();
```

```csharp
using System.Globalization;
using System.Net.Http.Headers;
using System.Net.Http.Json;
using Verto.Application.Dtos.Auth;

namespace Verto.Api.Tests.Infrastructure;

public static class AuthTestClient
{
    public const string Password = "strong-pass-123";

    public static string NewEmail() =>
        "user-" + Guid.NewGuid().ToString("N", CultureInfo.InvariantCulture) + "@example.com";

    public static async Task<AuthResponse> SignupAsync(HttpClient client, string? email = null)
    {
        ArgumentNullException.ThrowIfNull(client);

        var response = await client.PostAsJsonAsync(
            "/v1/auth/signup",
            new SignupRequest(email ?? NewEmail(), Password, "Tester"));
        response.EnsureSuccessStatusCode();
        return (await response.Content.ReadFromJsonAsync<AuthResponse>())!;
    }

    public static async Task<HttpClient> CreateAuthorizedClientAsync(ApiWebApplicationFactory factory)
    {
        ArgumentNullException.ThrowIfNull(factory);

        var client = factory.CreateClient();
        var auth = await SignupAsync(client);
        client.DefaultRequestHeaders.Authorization = new AuthenticationHeaderValue("Bearer", auth.AccessToken);
        return client;
    }
}
```

```csharp
using FluentValidation;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Options;
using Verto.Application.Abstractions.Auth;
using Verto.Application.Abstractions.Persistence;
using Verto.Application.Common;
using Verto.Application.Dtos.Auth;
using Verto.Domain.Entities;

namespace Verto.Application.UseCases.Auth;

public class AuthService
{
    private readonly IApplicationDbContext _db;
    private readonly IPasswordHasher _passwordHasher;
    private readonly IJwtTokenService _jwt;
    private readonly AuthOptions _options;
    private readonly IValidator<SignupRequest> _signupValidator;
    private readonly IValidator<LoginRequest> _loginValidator;
    private readonly IValidator<RefreshTokenRequest> _refreshValidator;
    private readonly IValidator<LogoutRequest> _logoutValidator;

    public AuthService(
        IApplicationDbContext db,
        IPasswordHasher passwordHasher,
        IJwtTokenService jwt,
        IOptions<AuthOptions> options,
        IValidator<SignupRequest> signupValidator,
        IValidator<LoginRequest> loginValidator,
        IValidator<RefreshTokenRequest> refreshValidator,
        IValidator<LogoutRequest> logoutValidator)
    {
        ArgumentNullException.ThrowIfNull(options);

        _db = db;
        _passwordHasher = passwordHasher;
        _jwt = jwt;
        _options = options.Value;
        _signupValidator = signupValidator;
        _loginValidator = loginValidator;
        _refreshValidator = refreshValidator;
        _logoutValidator = logoutValidator;
    }

    public async Task<OperationResult<AuthResponse>> SignupAsync(SignupRequest request, CancellationToken ct = default)
    {
        ArgumentNullException.ThrowIfNull(request);

        if (!_options.AllowSignup)
        {
            return OperationResult.Fail<AuthResponse>("signup_disabled", "Cadastro desativado.");
        }

        var validation = await _signupValidator.ValidateAsync(request, ct);
        if (!validation.IsValid)
        {
            return OperationResult.Fail<AuthResponse>("validation_error", validation.Errors[0].ErrorMessage);
        }

        var emailNormalized = request.Email.Trim().ToLowerInvariant();
        if (await _db.Users.AnyAsync(u => u.Email == emailNormalized, ct))
        {
            return OperationResult.Fail<AuthResponse>("email_already_registered", "Este email já está cadastrado.");
        }

        var user = new User
        {
            Id = Guid.CreateVersion7(),
            Email = emailNormalized,
            PasswordHash = _passwordHasher.Hash(request.Password),
            DisplayName = request.DisplayName.Trim(),
        };
        _db.Users.Add(user);

        var response = GenerateAndTrackTokens(user);
        await _db.SaveChangesAsync(ct);

        return OperationResult.Ok(response);
    }

    public async Task<OperationResult<AuthResponse>> LoginAsync(LoginRequest request, CancellationToken ct = default)
    {
        ArgumentNullException.ThrowIfNull(request);

        var validation = await _loginValidator.ValidateAsync(request, ct);
        if (!validation.IsValid)
        {
            return OperationResult.Fail<AuthResponse>("validation_error", validation.Errors[0].ErrorMessage);
        }

        var emailNormalized = request.Email.Trim().ToLowerInvariant();
        var user = await _db.Users.FirstOrDefaultAsync(u => u.Email == emailNormalized, ct);

        if (user is null || !_passwordHasher.Verify(request.Password, user.PasswordHash))
        {
            // Same message for unknown email and wrong password: no account enumeration.
            return OperationResult.Fail<AuthResponse>("invalid_credentials", "Email ou senha inválidos.");
        }

        var response = GenerateAndTrackTokens(user);
        await _db.SaveChangesAsync(ct);

        return OperationResult.Ok(response);
    }

    public async Task<OperationResult<AuthResponse>> RefreshAsync(RefreshTokenRequest request, CancellationToken ct = default)
    {
        ArgumentNullException.ThrowIfNull(request);

        var validation = await _refreshValidator.ValidateAsync(request, ct);
        if (!validation.IsValid)
        {
            return OperationResult.Fail<AuthResponse>("validation_error", validation.Errors[0].ErrorMessage);
        }

        var tokenHash = _jwt.ComputeTokenHash(request.RefreshToken);
        var now = DateTime.UtcNow;

        await using var transaction = await _db.BeginTransactionAsync(ct);

        var presentedToken = await _db.RefreshTokens
            .AsNoTracking()
            .Where(rt => rt.TokenHash == tokenHash && rt.RevokedAt == null && rt.ExpiresAt > now)
            .Select(rt => new { rt.User, rt.FamilyId })
            .SingleOrDefaultAsync(ct);

        if (presentedToken is null)
        {
            return OperationResult.Fail<AuthResponse>("invalid_refresh_token", "Refresh token inválido, revogado ou expirado.");
        }

        // Serializes concurrent refreshes of the same session so only one rotation wins.
        await _db.AcquireRefreshTokenFamilyLockAsync(presentedToken.FamilyId, ct);

        var revokedTokens = await _db.RefreshTokens
            .Where(rt => rt.TokenHash == tokenHash && rt.RevokedAt == null && rt.ExpiresAt > now)
            .ExecuteUpdateAsync(setters => setters.SetProperty(rt => rt.RevokedAt, now), ct);

        if (revokedTokens != 1)
        {
            return OperationResult.Fail<AuthResponse>("invalid_refresh_token", "Refresh token inválido, revogado ou expirado.");
        }

        var response = GenerateAndTrackTokens(presentedToken.User, presentedToken.FamilyId);
        await _db.SaveChangesAsync(ct);
        await transaction.CommitAsync(ct);

        return OperationResult.Ok(response);
    }

    public async Task<OperationResult<bool>> LogoutAsync(LogoutRequest request, CancellationToken ct = default)
    {
        ArgumentNullException.ThrowIfNull(request);

        var validation = await _logoutValidator.ValidateAsync(request, ct);
        if (!validation.IsValid)
        {
            return OperationResult.Fail<bool>("validation_error", validation.Errors[0].ErrorMessage);
        }

        var tokenHash = _jwt.ComputeTokenHash(request.RefreshToken);
        var now = DateTime.UtcNow;

        await using var transaction = await _db.BeginTransactionAsync(ct);

        // A rotated predecessor still identifies the session, so logging out with it
        // must also revoke any successor already issued.
        var familyId = await _db.RefreshTokens
            .AsNoTracking()
            .Where(rt => rt.TokenHash == tokenHash)
            .Select(rt => (Guid?)rt.FamilyId)
            .SingleOrDefaultAsync(ct);

        if (familyId.HasValue)
        {
            await _db.AcquireRefreshTokenFamilyLockAsync(familyId.Value, ct);
            await _db.RefreshTokens
                .Where(rt => rt.FamilyId == familyId.Value && rt.RevokedAt == null)
                .ExecuteUpdateAsync(setters => setters.SetProperty(rt => rt.RevokedAt, now), ct);
        }

        await transaction.CommitAsync(ct);

        return OperationResult.Ok(true);
    }

    private AuthResponse GenerateAndTrackTokens(User user, Guid? familyId = null)
    {
        var accessToken = _jwt.GenerateAccessToken(user.Id, user.Email);
        var (refreshToken, refreshHash, refreshExpiresAt) = _jwt.GenerateRefreshToken();

        _db.RefreshTokens.Add(new RefreshToken
        {
            Id = Guid.CreateVersion7(),
            UserId = user.Id,
            FamilyId = familyId ?? Guid.CreateVersion7(),
            TokenHash = refreshHash,
            ExpiresAt = refreshExpiresAt,
        });

        return new AuthResponse(
            AccessToken: accessToken.Token,
            RefreshToken: refreshToken,
            AccessTokenExpiresAt: accessToken.ExpiresAt,
            RefreshTokenExpiresAt: refreshExpiresAt,
            User: new UserDto(user.Id, user.Email, user.DisplayName));
    }
}
```

```csharp
using System.Buffers.Binary;
using Microsoft.EntityFrameworkCore;
using Microsoft.EntityFrameworkCore.Storage;
using Verto.Application.Abstractions.Persistence;
using Verto.Domain.Entities;

namespace Verto.Infrastructure.Persistence;

public class ApplicationDbContext : DbContext, IApplicationDbContext
{
    public ApplicationDbContext(DbContextOptions<ApplicationDbContext> options) : base(options) { }

    public DbSet<User> Users => Set<User>();
    public DbSet<RefreshToken> RefreshTokens => Set<RefreshToken>();

    public async Task<IApplicationDbTransaction> BeginTransactionAsync(CancellationToken cancellationToken = default)
    {
        var transaction = await Database.BeginTransactionAsync(cancellationToken);
        return new ApplicationDbTransaction(transaction);
    }

    public Task AcquireRefreshTokenFamilyLockAsync(Guid familyId, CancellationToken cancellationToken = default)
    {
        return Database.ExecuteSqlInterpolatedAsync(
            $"SELECT pg_advisory_xact_lock({AdvisoryLockKey.From(familyId)})",
            cancellationToken);
    }

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        ArgumentNullException.ThrowIfNull(modelBuilder);

        modelBuilder.ApplyConfigurationsFromAssembly(typeof(ApplicationDbContext).Assembly);
    }

    private sealed class ApplicationDbTransaction(IDbContextTransaction transaction) : IApplicationDbTransaction
    {
        public Task CommitAsync(CancellationToken cancellationToken = default) => transaction.CommitAsync(cancellationToken);

        public ValueTask DisposeAsync() => transaction.DisposeAsync();
    }
}

public static class AdvisoryLockKey
{
    public static long From(Guid id)
    {
        Span<byte> bytes = stackalloc byte[16];
        id.TryWriteBytes(bytes);
        return BinaryPrimitives.ReadInt64LittleEndian(bytes);
    }
}
```

```csharp
using System.Text;
using System.Text.Json;
using Verto.Application.Dtos.Sync;

namespace Verto.Application.UseCases.Sync;

/// <summary>
/// Format-only validation. Field values are the client's business; the server
/// only guarantees each stored record has the shape the client will read back.
/// </summary>
public static class SyncEntityCatalog
{
    public const int MaxPayloadBytes = 64 * 1024;

    private static readonly Dictionary<string, string[]> RequiredFields = new(StringComparer.Ordinal)
    {
        ["inbox_item"] = ["text", "createdAt", "source", "state"],
        ["task"] = ["title", "pinnedToToday"],
        ["step"] = ["order", "title", "energy"],
        ["anchor"] = ["name", "windowStart", "windowEnd"],
        ["anchor_event"] = ["anchorId", "day", "triggeredAt", "source"],
        ["routine"] = ["name", "anchorId", "weekdays"],
        ["routine_log"] = ["routineId", "day", "outcome"],
        ["day_energy"] = ["day", "level", "setAt"],
    };

    public static string? Validate(SyncChangeIn change)
    {
        ArgumentNullException.ThrowIfNull(change);

        if (string.IsNullOrEmpty(change.EntityType) || !RequiredFields.TryGetValue(change.EntityType, out var required))
        {
            return "unknown_entity_type";
        }

        if (change.Id == Guid.Empty)
        {
            return "invalid_id";
        }

        if (change.ClientUpdatedAt == default)
        {
            return "missing_client_updated_at";
        }

        if (change.Payload.ValueKind != JsonValueKind.Object)
        {
            return "payload_must_be_object";
        }

        if (Encoding.UTF8.GetByteCount(change.Payload.GetRawText()) > MaxPayloadBytes)
        {
            return "payload_too_large";
        }

        // Tombstones may be sent with a minimal payload.
        if (change.DeletedAt is not null)
        {
            return null;
        }

        foreach (var field in required)
        {
            if (!change.Payload.TryGetProperty(field, out _))
            {
                return "missing_field:" + field;
            }
        }

        if (string.Equals(change.EntityType, "step", StringComparison.Ordinal) && !HasStepOwner(change.Payload))
        {
            return "missing_field:taskId|routineId+plan";
        }

        return null;
    }

    private static bool HasStepOwner(JsonElement payload)
    {
        return payload.TryGetProperty("taskId", out _)
            || (payload.TryGetProperty("routineId", out _) && payload.TryGetProperty("plan", out _));
    }
}
```

```csharp
using Verto.Application.Abstractions.Sync;
using Verto.Application.Common;
using Verto.Application.Dtos.Sync;

namespace Verto.Application.UseCases.Sync;

public sealed class SyncService
{
    public const int MaxBatchSize = 500;
    public const int DefaultPullLimit = 500;
    public const int MaxPullLimit = 1000;

    private readonly ISyncStore _store;

    public SyncService(ISyncStore store)
    {
        _store = store;
    }

    public async Task<OperationResult<PushResponse>> PushAsync(
        Guid userId,
        PushRequest request,
        CancellationToken ct = default)
    {
        ArgumentNullException.ThrowIfNull(request);

        if (request.Changes is null || request.Changes.Count == 0)
        {
            return OperationResult.Fail<PushResponse>("validation_error", "Envie ao menos uma mudança.");
        }

        if (request.Changes.Count > MaxBatchSize)
        {
            return OperationResult.Fail<PushResponse>("validation_error", "Máximo de 500 mudanças por push.");
        }

        var accepted = new List<SyncChangeIn>(request.Changes.Count);
        var rejected = new List<PushRejected>();

        foreach (var change in request.Changes)
        {
            if (change is null)
            {
                rejected.Add(new PushRejected(string.Empty, Guid.Empty, "invalid_change"));
                continue;
            }

            var error = SyncEntityCatalog.Validate(change);
            if (error is null)
            {
                accepted.Add(change);
            }
            else
            {
                rejected.Add(new PushRejected(change.EntityType ?? string.Empty, change.Id, error));
            }
        }

        IReadOnlyList<long> versions = accepted.Count == 0
            ? []
            : await _store.UpsertBatchAsync(userId, accepted, ct);

        var acceptedOut = accepted
            .Select((change, index) => new PushAccepted(change.EntityType, change.Id, versions[index]))
            .ToList();

        return OperationResult.Ok(new PushResponse(acceptedOut, rejected));
    }
}
```

```csharp
using System.Text.Json;
using Npgsql;
using NpgsqlTypes;
using Verto.Application.Abstractions.Sync;
using Verto.Application.Dtos.Sync;
using Verto.Infrastructure.Persistence;

namespace Verto.Infrastructure.Sync;

public sealed class SyncStore : ISyncStore
{
    // nextval runs even on conflict, so EXCLUDED.server_version carries the new version.
    private const string UpsertSql = """
        INSERT INTO sync_records
            (user_id, entity_type, id, payload, deleted_at, client_updated_at, server_version, received_at)
        VALUES ($1, $2, $3, $4, $5, $6, nextval('sync_version_seq'), now())
        ON CONFLICT (user_id, entity_type, id) DO UPDATE SET
            payload = EXCLUDED.payload,
            deleted_at = EXCLUDED.deleted_at,
            client_updated_at = EXCLUDED.client_updated_at,
            server_version = EXCLUDED.server_version,
            received_at = EXCLUDED.received_at
        RETURNING server_version
        """;

    private const string ReadSql = """
        SELECT entity_type, id, payload::text, deleted_at, server_version
        FROM sync_records
        WHERE user_id = $1 AND server_version > $2
        ORDER BY server_version
        LIMIT $3
        """;

    private readonly NpgsqlDataSource _dataSource;

    public SyncStore(NpgsqlDataSource dataSource)
    {
        _dataSource = dataSource;
    }

    public async Task<IReadOnlyList<long>> UpsertBatchAsync(
        Guid userId,
        IReadOnlyList<SyncChangeIn> changes,
        CancellationToken ct)
    {
        ArgumentNullException.ThrowIfNull(changes);

        await using var connection = await _dataSource.OpenConnectionAsync(ct);
        await using var transaction = await connection.BeginTransactionAsync(ct);

        // Pushes for one user are serialized so their versions commit in order;
        // otherwise a pull could advance its cursor past a still-uncommitted lower version.
        await using (var lockCommand = new NpgsqlCommand("SELECT pg_advisory_xact_lock($1)", connection, transaction))
        {
            lockCommand.Parameters.Add(new NpgsqlParameter { Value = AdvisoryLockKey.From(userId) });
            await lockCommand.ExecuteNonQueryAsync(ct);
        }

        var versions = new List<long>(changes.Count);
        foreach (var change in changes)
        {
            await using var command = new NpgsqlCommand(UpsertSql, connection, transaction);
            command.Parameters.Add(new NpgsqlParameter { Value = userId });
            command.Parameters.Add(new NpgsqlParameter { Value = change.EntityType });
            command.Parameters.Add(new NpgsqlParameter { Value = change.Id });
            command.Parameters.Add(new NpgsqlParameter { Value = change.Payload.GetRawText(), NpgsqlDbType = NpgsqlDbType.Jsonb });
            command.Parameters.Add(new NpgsqlParameter
            {
                Value = change.DeletedAt is { } deletedAt ? (object)deletedAt.UtcDateTime : DBNull.Value,
                NpgsqlDbType = NpgsqlDbType.TimestampTz,

            {
                Value = change.ClientUpdatedAt.UtcDateTime,
                NpgsqlDbType = NpgsqlDbType.TimestampTz,
            });

            var version = await command.ExecuteScalarAsync(ct);
            versions.Add((long)version!);
        }

        await transaction.CommitAsync(ct);
        return versions;
    }

    public async Task<IReadOnlyList<SyncChangeOut>> ReadSinceAsync(
        Guid userId,
        long since,
        int limit,
        CancellationToken ct)
    {
        await using var command = _dataSource.CreateCommand(ReadSql);
        command.Parameters.Add(new NpgsqlParameter { Value = userId });
        command.Parameters.Add(new NpgsqlParameter { Value = since });
        command.Parameters.Add(new NpgsqlParameter { Value = limit });

        var rows = new List<SyncChangeOut>();
        await using var reader = await command.ExecuteReaderAsync(ct);
        while (await reader.ReadAsync(ct))
        {
            using var payload = JsonDocument.Parse(reader.GetString(2));
            rows.Add(new SyncChangeOut(
                EntityType: reader.GetString(0),
                Id: reader.GetGuid(1),
                Payload: payload.RootElement.Clone(),
                DeletedAt: reader.IsDBNull(3) ? null : reader.GetFieldValue<DateTimeOffset>(3),
                ServerVersion: reader.GetInt64(4)));
        }

        return rows;
    }
```

```csharp
    public async Task<OperationResult<PullResponse>> PullAsync(
        Guid userId,
        long since,
        int? limit,
        CancellationToken ct = default)
    {
        if (since < 0)
        {
            return OperationResult.Fail<PullResponse>("validation_error", "O cursor não pode ser negativo.");
        }

        var pageSize = Math.Clamp(limit ?? DefaultPullLimit, 1, MaxPullLimit);

        // One extra row tells whether another page exists without a COUNT query.
        var rows = await _store.ReadSinceAsync(userId, since, pageSize + 1, ct);
        var hasMore = rows.Count > pageSize;
        var page = hasMore ? rows.Take(pageSize).ToList() : rows;
        var cursor = page.Count == 0 ? since : page[^1].ServerVersion;

        return OperationResult.Ok(new PullResponse(page, cursor, hasMore));
    }
```
